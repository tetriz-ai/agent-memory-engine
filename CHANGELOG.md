## [0.1.0] - 2026-10-28

### Added

- Initial public release.
- The `tetriz-agent-memory-engine` CLI and Python package for extracting typed, tagged memories
  from local Claude Code sessions, with source quotes checked against the transcript.
- Session previews, facts and preferences extraction, and ranked memory output with Gemini,
  the local Claude CLI, or a custom model provider.
- A documented JSON Schema and runnable examples using synthetic sessions and recorded answers.
